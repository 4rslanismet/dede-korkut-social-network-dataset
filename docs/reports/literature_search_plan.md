# Literature Search Plan

Per the project brief (section 97), this Colab/local pipeline session did not perform internet
literature research. This document records the concepts and search queries a researcher should
use to situate this project's findings against prior work, for `paper/manuscript_outline.md` §2
(Related Work).

## Concepts to compare against

- Literary network analysis / narrative social networks (general methodology)
- Multilayer / multiplex literary networks
- Digital humanities network analysis (methodology and tooling)
- Epic narrative networks (comparable corpora: e.g. Homeric epics, medieval sagas, other Turkic
  epic cycles)
- Computational analysis of the Book of Dede Korkut specifically (prior work, if any)
- Null-model / statistical validation practice for social/literary networks (relevant to this
  project's central methodological finding — the retracted assortativity claim)
- Degree-preserving randomization and configuration models
- Community detection stability and resolution sensitivity (Leiden/Louvain comparisons)
- Structural robustness and "robust yet fragile" network behavior (Albert-Jeong-Barabási and
  successors)
- Entity resolution / canonicalization in hand-coded humanities datasets
